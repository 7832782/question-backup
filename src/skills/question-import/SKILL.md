# 题库录入（question-import）

把任意来源的题目规范化导入本地题库系统。题库系统是 Go 单二进制 + SQLite，运行在 `http://127.0.0.1:8787`（exe 位于 `D:\desktop\题库系统\题库系统.exe`，无参启动自动开浏览器；数据在 `data.db`，源码在 `src/`）。

## 触发场景

- 用户提供题源（笔记 md、上课记录、网页、PDF、截图、聊天文本），要求入库
- 用户说「把这些题导入」「收进题库」「录入」「存题」等，即使没有明说「题库」二字，只要语境是本系统就触发
- 注意区分：如果用户只是要「整理笔记」「生成练习文档」而非入库，不要触发

## 工作流程

### 1. 定位题源并提取题目

先找到题源文件（必要时询问用户），然后提取每道题的六要素：

| 要素 | 来源 |
|---|---|
| 题干 body | 题目正文（保留 LaTeX 公式原文 `$...$` / `$$...$$`） |
| 选项 options | 选择题的选项内容（**不存字母前缀**，系统自动生成 A/B/C/D） |
| 答案 answer | 选择题存字母（"B"、"BC"）；非选择题存答案文本 |
| 解析 analysis | 参考答案/解析/解题过程（可有可无，有则存） |
| 题型 qtype | 单选 / 多选 / 填空 / 解答 |
| 难度 difficulty | 1-5 星 |

**PDF 题源（数学卷必须走视觉）**：`office_read-document` 的文本提取会把数学符号毁掉（`√3`→`p 3`、`π`→``、`α/β` 直接丢），纯文本卷子可以用，数学卷**一定**要用下面的视觉流程：

1. 运行 `scripts/render_pdf.py`（改 PDF 路径）把每页渲染成高清 PNG（2.2x 缩放，约 160 DPI）
2. 用 read 工具逐张读 PNG（图片会作为附件进视觉上下文），从图里提取题干、选项、图
3. 只有 pymupdf 缺失时才先装：`python -m pip install pymupdf -i https://pypi.tuna.tsinghua.edu.cn/simple`（默认源容易超时）
4. 图中几何体/曲线是题干的一部分，视觉能读到结构（如四棱锥顶点位置、曲线过原点带环），题干文字完整描述后不需要补图
5. **题干必需图要从 PDF 抠出来入库**：先用视觉在整页渲染图（`page_N.png`）上定位图的像素区域，再用 pymupdf 对局部高分辨率渲染：`page.get_pixmap(matrix=fitz.Matrix(4,4), clip=fitz.Rect(x0,y0,x1,y1))`（像素坐标 ÷ 渲染倍率 = PDF 坐标），然后用 PIL 裁白边、缩放宽 ≤1600、JPEG quality 88 白底，PUT 更新题目时放进 `images: [{position: 0, data: <完整 data URI>, width: <px>}]`。**data 必须是完整 data URI（`data:image/jpeg;base64,` 前缀 + base64）**——前端压缩图和渲染 `<img src>` 都按此格式，只存纯 base64 会破图（2024-08-04 踩过：3 张图全部显示为破图 + alt 文字「图1」）

源文件常见的练习题结构：`📝 练习题`、`巩固练习`、`作业`、`例题`、`变式题`、`参考答案` 等标题。没有明显「练习」标题的文件也要检查是否有例题/变式题（这些也是题）。图片引用（`![](路径)`）不要导入为占位符，直接忽略或提醒用户后续用 UI 补图；表格保留 markdown 原文放进 body 或 answer。

### 2. 规范化 JSON

每道题一个对象，字段（与系统 API 一致）：

```json
{
  "subject": "数学",
  "grade": "初中",
  "qtype": "解答",
  "difficulty": 3,
  "tags": ["数列"],
  "source": "高中上课0729",
  "body": "题干，$公式$ 保留 LaTeX 原文，多小问用（1）（2）（3）分行",
  "options": ["选项1", "选项2", "选项3", "选项4"],
  "answer": "B",
  "analysis": "解析要点"
}
```

**字段规则（违反会导致显示异常，务必遵守）：**

- `qtype` 只能是英文枚举：`single` / `multi` / `fill` / `essay`（单选/多选/填空/解答），**不要存中文**（导出按英文键映射题型名，前端 QTYPE_NAME 也是英文键；2024-08-04 曾因中英混存导致相似题题型徽章空白）
- `grade` 只能是：`小学` / `初中` / `高中` / `大学`
- `difficulty` 1-5 整数
- `options` 只对单选/多选填，内容**不带 "A. " 前缀**（系统自动加字母）；填空/解答不填 options
- `answer` 单选/多选存字母（多选如 "BC"），填空/解答存文本
- `tags` 必须是**该科目该年级的大知识点**（见 references/tag-map.md），不要用细碎标签（如「垂径定理」→「圆」）
- `source` 记录出处，格式：`初中上课0803`、`高中上课0731`、`2024新高考I卷`、`原创` 等；同一天多份文件加后缀 `-2`
- 公式一律保留 `$...$` / `$$...$$` LaTeX 原文，不要转成 Unicode 或图片
- 多小问题目：题干里用（1）（2）（3）分行列出；answer 里对应（1）（2）（3）作答

### 3. 映射大知识点标签

打开 `references/tag-map.md`，按「科目 + 年级」查表，把源标签映射到规范大类。映射原则：

- 初中题必须用初中 11 类，高中题必须用高中 10 类，**同名不同级是不同标签**
- 表中没有的细标签，按语义归入最近的大类（如「等差数列前n项和」→「数列」）
- 拿不准的：归入语义最近的大类并在导入后提醒用户可在「标签」页调整

### 4. 去重检查

创建接口**不做自动去重**，导入前必须自己查重：对每题用 `GET /api/questions?search=<题干前 12-20 字>`（URL 编码），若命中同科目同年级同题干，跳过并报告。搜索用题干开头片段即可（系统按题干/答案/解析子串匹配）。

### 5. 导入

用 `scripts/import_template.py` 模板（复制到 `src/` 下改 QUESTIONS 列表），逐题 `POST /api/questions`。要求：

- 脚本运行前提：题库系统 exe 正在运行（`http://127.0.0.1:8787` 可访问）
- 每道题一个请求，打印导入结果（code + 题干前 24 字）
- 导入完成后打印统计：新增 X 题、跳过重复 Y 题
- 导入数据量大（>30 题）时建议拆成多批，每批跑完检查输出

### 6. 验证

- `GET /api/questions?pageSize=200` 核对总数与预期一致
- 按 `source` 筛选核对本批题都在
- 抽查 1-2 道题详情：公式渲染正常、选项字母正确、答案正确
- 检查 `GET /api/tags/manage?subject=数学&grade=初中/高中` 标签统计，确认没有跑出规范大类之外的标签（有则说明映射漏了，回头修正）

## 常见坑

- **真题解析必须核实**：高考真题（尤其压轴证明题）的解析不能凭记忆写，先 web_search 官方答案/权威解析核对再入库，否则容易出现「看起来像那么回事但证明不严谨」的解析（实例：2024 新高考Ⅰ卷 19 题 (3) 的证明有第二族构造，第一族极限只有 1/16 < 1/8，光靠平移组合证不出来）

- **PowerShell 传 Python 多行 `-c` 必炸**：不要用 `python -c "多行代码"`，一律写临时 .py 文件再执行
- **公式转义**：Python 字符串里写 `$...$` 时，`\d`、`\f` 等会被转义，用 `\\d` 或原始字符串；导入脚本里统一用 `\\` 前缀
- **pageSize 上限**：`GET /api/questions?pageSize=300` 只返回 50 条（已知怪癖），要全量用 `pageSize=200`
- **不要动测试脚本**：`src/test_api.py` 自带 cleanup 会清空所连库，绝不对正式服务跑
- **物理科目暂未建大知识点**：物理题先不入库，等用户定义
