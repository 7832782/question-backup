# 大知识点映射表（题库标签规范）

标签按「科目 + 年级」独立管理。题库题目上的标签**只能使用下表的大知识点**。同名标签在不同年级下是不同实体（数学初中的「函数」≠ 数学高中的「函数与导数」）。

## 初中数学（11 类）

| 大知识点 | 常见子标签/细知识点（合并进大类） |
|---|---|
| 数与式 | 有理数、实数、整式、幂运算、乘法公式、因式分解、分式、二次根式、相反数、绝对值、倒数 |
| 方程与不等式 | 一元一次方程、二元一次方程组、分式方程、一元二次方程、不等式（组） |
| 函数 | 函数基础、一次函数、反比例函数、二次函数、函数图像、锐角三角函数、解直角三角形 |
| 角与平行线 | 点线面、角、余角与补角、平行线的判定、平行线性质、线段公理 |
| 三角形 | 全等三角形、三角形内角和、外角、三边关系、等腰、等边、中位线、勾股定理（含应用/逆定理/勾股数） |
| 四边形 | 平行四边形（含判定/性质）、矩形、菱形、正方形、多边形（内角和/外角和/正多边形） |
| 圆 | 垂径定理、圆周角定理、弧长、扇形、直线与圆的位置关系、切线 |
| 图形的变化 | 平移、旋转、轴对称、中心对称、相似（三角形/位似）、投影与视图 |
| 图形与坐标 | 平面直角坐标系 |
| 抽样与数据分析 | 平均数、中位数、众数、方差、抽样调查、样本估计总体、直方图 |
| 随机事件的概率 | 概率、列表法、树状图、频率估计 |

注意：相似三角形按笔记归属「图形的变化」；锐角三角函数/解直角三角形按笔记归属「函数」。

## 高中数学（10 类）

| 大知识点 | 常见子标签/细知识点（合并进大类） |
|---|---|
| 集合与常用逻辑用语 | 集合、命题、充分必要条件、量词 |
| 函数与导数 | 函数概念与性质、基本初等函数、函数零点、导数运算、单调性极值最值、指数型复合函数 |
| 三角函数与解三角形 | 任意角、弧度制、三角恒等变换、图象性质、正弦余弦定理 |
| 平面向量 | 向量运算、数量积、坐标运算 |
| 数列 | 等差数列、等比数列、递推公式、累加累乘、错位相减、裂项相消、分组求和、Sn 最值 |
| 不等式 | 一元二次不等式、基本不等式 |
| 立体几何与空间向量 | 空间几何体、三视图、线面关系、空间向量 |
| 解析几何 | 直线与圆、椭圆、双曲线、抛物线 |
| 计数原理与概率统计 | 排列组合、二项式定理、概率、条件概率、正态分布、回归分析、独立性检验、抽样、统计量 |
| 复数 | 复数概念、四则运算 |

- **大学**：暂无规范标签，暂不入库
