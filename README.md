# 题库系统

本地题库管理与组卷工具。双击 exe 即用，数据全部存在本地。

## 快速开始

1. 双击 `题库系统.exe`，自动打开浏览器（地址 `http://127.0.0.1:8787`）
2. 在「题库」页点「+ 新建题目」录入题目（支持图片上传自动压缩、Markdown 表格、LaTeX 公式）
3. 在「组卷」页选题组卷，导出为 Markdown

## 数据文件

- `data.db`：全部数据（题目、图片、表格、卷子），与 exe 同目录
- 备份 = 复制 `data.db` 一个文件
- 迁移 = 复制 exe + data.db 到新电脑，或使用「导入导出」页的 JSON 快照

## 功能一览

### 题库
- 字段：编号、科目、题型（单选/多选/填空/解答）、难度（1-5星）、知识点标签（多值）、来源、题干、选项、答案、解析、使用次数
- 图片：上传自动压缩（白底 JPEG，最长边 1600px），每张图可设显示宽度（30%-100%），正文用 `{{图1}}` 占位符引用
- 表格：Markdown 语法，正文用 `{{表1}}` 占位符引用
- 公式：LaTeX 直接写 `$...$`
- 筛选：科目、题型、难度区间、标签、来源、全文搜索、「未使用过」
- 删除被卷子引用的题：提示引用数，确认后删除，卷中标记「题目已删除」

### 组卷
- 勾选题目（或从组卷页的「从题库添加」）→ 调整顺序和分值 → 保存卷子
- 卷子只存题目引用：改原题，所有卷子自动同步；删题只影响该题
- 已存卷可随时打开、增删、另存

### 导出 Markdown
- 按题型分组（一、单项选择题（共 N 题，每题 X 分）…），题号跨组连续
- 选项竖排，图片内嵌 base64（单文件即可分享，Typora / Obsidian / VS Code 均可打开）
- 答案、解析独立开关，位置可选「每题后」或「卷尾集中」
- 文件名：卷名_日期.md

### 导入导出
- 快照导出：全部题目打包为 JSON（备份/迁移）
- 快照导入：按题干自动去重，可选覆盖更新

## 开发

- 源码：`src/`（Go 后端 + 原生 JS 前端，前端静态资源内嵌进 exe）
- 构建：`powershell -ExecutionPolicy Bypass -File src\build.ps1`
- 测试：`python src\test_api.py`（需先启动服务）
- 端口：默认 8787，被占用时自动 +1
